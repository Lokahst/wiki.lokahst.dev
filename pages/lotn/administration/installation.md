## Server Requirement

LotN `1.0.10` requires Java 21 and is compiled against Paper API `1.21.11`. Use a compatible Paper server.

## Soft Dependencies

| Plugin | Required | Used for |
|---|---|---|
| Vault and an economy provider | No | Balances, money rewards, and Fish Exchange sales |
| PlaceholderAPI | No | `%lotn_*%` placeholders |
