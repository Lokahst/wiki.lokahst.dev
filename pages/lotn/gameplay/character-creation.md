## Character Name

A character can use the player's Minecraft username or a separate name entered in chat.

| Setting | Default |
|---|---|
| Minimum length | 3 characters |
| Maximum length | 20 characters |
| Unique names | Yes |
| Cancel word | `cancel` |
| Allowed pattern | `[A-Za-z][A-Za-z0-9 _'\-]*` |

The name must start with a letter. After that, it may contain numbers, spaces, apostrophes, underscores, and hyphens. The default name blacklist is empty.
